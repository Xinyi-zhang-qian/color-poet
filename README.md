# 色彩诗卡 · ColorPoet 🎨

> 上传一张照片，AI 为你提取主色调，绘一幅抽象色彩画，配一只可爱动漫动物，题一句经典名句。

**ColorPoet** 是一个 AI Agent 网页应用：它把一张真实的照片，转化为一份「色彩 × 图像 × 文学」的艺术卡片——从画面中提炼主色搭配，生成只属于这张照片的抽象色彩构成，再召唤一只配色呼应的可爱动漫动物，最后从海子、顾城、泰戈尔、罗素、苏格拉底等经典作品里，挑一句与画面情绪相配的名句。

---

## ✨ 功能特性

- 🎨 **智能取色** — 基于 CIE Lab 色彩空间 + K-means 聚类，提取 6 个主色并判断画面情绪（暖/冷/中性、明/暗）
- 🖼️ **抽象色彩画** — 4 种纯算法 SVG 风格：极光幻梦 / 蒙德里安 / 柔光渐变 / 流体涟漪，色彩 100% 贴合提取结果
- 🐾 **可爱动漫动物** — 调用通义万相文生图，把主色调写进提示词，生成配色呼应的 Q 版动漫动物（可自由指定任意动物）
- 📜 **经典名句** — 内置 60 条真实可查证的中外名句（标注作者与出处），按画面情绪智能匹配，绝不编造
- 🤖 **Agent 编排** — 感知 → 决策 → 并行执行 → 组装；通义千问可选增强意境理解，无 Key 时自动降级为规则引擎
- 🖥️ **艺术感网页** — 拖拽上传、色卡点击复制、一键换风格 / 换动物 / 换诗句、下载竖版诗卡海报

---

## 🎬 使用流程

打开网页即可用内置的 4 张示例图（夕阳 / 海洋 / 森林 / 极光）一键体验，也可以上传自己的照片。

```
上传照片 → 即时提取调色板 → 选择动物与抽象风格
        → 一键生成 → 抽象画 + 动漫动物 + 名句 → 下载诗卡海报
```

## 🚀 快速开始

### 1. 环境要求

- Node.js ≥ 20
- pnpm ≥ 9

### 2. 安装依赖

```bash
pnpm install
```

### 3. 配置 API Key

```bash
cp .env.example .env
```

编辑 `.env`，填入阿里云百炼 API Key（用于通义万相图像生成）：

```env
DASHSCOPE_API_KEY=sk-你的密钥
```

> Key 获取地址：[百炼控制台](https://bailian.console.aliyun.com/) → API-KEY 管理。`.env` 已被 git 忽略，不会提交到仓库。
> 未配置 Key 时应用仍可运行（动物以可爱占位展示），配置后即可生成真实 AI 动物。

### 4. 启动开发环境

```bash
pnpm dev
```

- 前端：http://localhost:5173 （自动代理 `/api` 到后端）
- 后端：http://localhost:8787

## 📡 API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/generate` | 上传图片，生成完整结果（调色板 + 抽象图 + 动物 + 名句） |
| POST | `/api/palette` | 仅提取调色板 |
| POST | `/api/animal` | 换一只动物（重新生成） |
| POST | `/api/quote` | 换一句名句 |
| POST | `/api/abstract` | 切换抽象画风格 |
| GET | `/api/health` | 健康检查 |
| GET | `/api/meta` | 前端配置（动物池 / 风格列表） |

## 📜 名句来源说明

名句库精选 60 条真实经典句子，以现代诗与哲学家 / 文学家名言为主，并少量点缀意境极佳的古典诗词。所有条目均标注作者，能确证出处的附作品名（如海子《面朝大海，春暖花开》、罗素《我为什么而活着》、泰戈尔《飞鸟集》等）。匹配逻辑依据画面情绪（暖 / 冷 / 中性 × 明 / 暗）打分，不依赖模型「背诵」，从而保证出处真实可查。
