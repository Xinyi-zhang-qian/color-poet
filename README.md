# 生命之流彩 · Flow of Life ✨

> 用卡片点亮一束光 —— 上传照片、说一句话，或直接抽取，得到一张属于你此刻的色彩诗卡。

**一切如其所是，处处都是丰盛；样样都是完美，爱无处不在！**

这是一个 AI Agent 网页应用：它把一张照片、一句话或一次随机的灵感，转化为一张艺术收藏卡——从画面或文字意境中提炼主色调，生成抽象色彩画，召唤一只配色呼应的可爱动漫动物，再从杨定一、克里希那穆提、一行禅师、拜伦·凯蒂、拉玛那·马哈希、埃克哈特·托利等灵性导师的经典作品中，题一句与当下心境相配的话。

---

## ✨ 三种抽卡方式

| 方式 | 说明 |
|------|------|
| 🎲 **直接抽卡** | 无需任何输入，一键随机生成和谐配色与卡片 |
| 💬 **一句话抽卡** | 输入一句话，通义千问感受意境，生成契合的配色与动物 |
| 🖼️ **照片抽卡** | 上传真实照片，提取主色调生成卡片 |

---

## ✨ 功能特性

- 🎨 **智能取色** — CIE Lab 色彩空间 + K-means 聚类，提取 6 个主色并判断情绪（暖/冷/中性、明/暗）
- 🖼️ **抽象色彩画** — 6 种纯算法 SVG 风格：极光幻梦 / 蒙德里安 / 柔光渐变 / 流体涟漪 / 油画质感 / 绚烂霓虹
- 🐾 **可爱动漫动物** — 通义万相文生图，把主色调写进提示词，生成配色呼应的 Q 版动漫动物
- 📜 **经典名句** — 30 条真实可查证的灵性导师名句（标注作者与出处），按情绪匹配
- 🤖 **Agent 编排** — 感知 → 决策 → 并行执行 → 组装；通义千问增强意境理解，失败自动降级
- 🖥️ **抽卡式界面** — 明亮艺术感设计，诗句印在画中、动物在角落，可下载竖版诗卡海报

## 🚀 快速开始

### 1. 环境要求

- Node.js ≥ 20
- pnpm ≥ 9

### 2. 安装依赖

```bash
pnpm install
```

### 3. 配置 API Key

```bash
cp .env.example .env
```

编辑 `.env`，填入阿里云百炼 API Key（用于通义万相图像生成与通义千问文字分析）：

```env
DASHSCOPE_API_KEY=sk-你的密钥
```

> Key 获取地址：[百炼控制台](https://bailian.console.aliyun.com/) → API-KEY 管理。`.env` 已被 git 忽略，不会提交到仓库。
> 未配置 Key 时仍可运行（随机色板 + 抽象画 + 名句，动物以占位展示）。

### 4. 启动

```bash
pnpm dev
```

- 前端：http://localhost:5173 （自动代理 `/api` 到后端）
- 后端：http://localhost:8787

## 📡 API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/generate` | 上传图片抽卡 |
| POST | `/api/text-card` | 一句话抽卡 |
| POST | `/api/random-card` | 直接抽卡（随机） |
| POST | `/api/palette` | 仅提取照片调色板 |
| POST | `/api/animal` | 换一只动物 |
| POST | `/api/quote` | 换一句名句 |
| POST | `/api/abstract` | 切换抽象画风格 |
| GET | `/api/health` | 健康检查 |
| GET | `/api/meta` | 前端配置 |

## 📜 名句来源说明

名句库精选 30 条真实可查证的句子，来自六位灵性导师：杨定一博士、克里希那穆提、一行禅师、拜伦·凯蒂、拉玛那·马哈希、埃克哈特·托利。所有条目均标注作者，能确证出处的附书名（如杨定一《全部的你》、克里希那穆提《生命之书》、一行禅师《正念的奇迹》、拜伦·凯蒂《一念之转》、拉玛那·马哈希《走向静默，如你本来》、埃克哈特·托利《当下的力量》等）。
